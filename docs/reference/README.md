# docs/reference — the primary project documents

Read these first; everything else in `docs/` is a spec or an operating guide that
these documents cite.

| Document | What it is | Read it when |
|---|---|---|
| `BIDE_HLD.md` / `BIDE_HLD.html` | High-level design: context, containers, components, data stores, runtime sequences, integration, security, deployment, decisions, risks. The `.html` carries the diagrams. | You need to know what the parts are and how they talk |
| `BIDE_BUILD_REFERENCE.md` | Build reference: how everything is stored and referenced, how the agent runs, orchestrator and harness, tools and MCP, all thirteen fields, the Tally bridge, the path to becoming the ERP, the Vinayak rollout | You are building or extending a field, a source, or the runtime |
| `BIDE_STAGE_REVIEW.md` | Where the product stands against its own documents, what the finance vertical lacks, the decision-oriented dashboard, the background agent, and the sequence | You are deciding what to build next |
| `PLAN.md` | The week-by-week delivery plan against the milestones; also the 90-day plan and the proposed month-3 / month-6 demo criteria | You are planning a sprint or re-dating after a slip |
| `MILESTONES.md` | The contractual milestones with each criterion mapped to code status | You are planning a month or preparing a review |

The product rationale these derive from is `docs/vinayak/The_Business_IDE_BIDE.docx`.
