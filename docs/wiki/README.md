# Wiki

The working knowledge of the project — the things a new person (or the
brain) needs that are not in the code. Kept small, current, and in plain
language. The product reference documents live in `docs/reference/`; this
wiki is for what we learn while building and operating.

| Page | What it holds |
|---|---|
| `business-dictionary.md` | Every term on a screen, in words an engineer with no finance background can read |
| `data-sources.md` | Each source we sync: what it is, what it gives, its quirks, how to reconnect it |
| `decisions.md` | Decisions we made and why — one line each, dated, newest first |
| `companies/` | One page per Vinayak company: workspace id, source, contacts, owner, quirks |
| `learnings.md` | Things that surprised us and what we do differently now |
| `onboarding-runbook.md` | The steps to bring a new company onto BIDE |

Rules: date every entry; never paste credentials; when a decision changes,
add a new line rather than editing the old one.
